# Titulo de descrição: 
calculadora de media
## Tecnologias usadas:
 Python 3.14 version
**como instalar e executar*** 
através de compiladores online exemplo :(https://www.mycompiler.io/pt/new/python)

'''exemplo de uso ou demostração:...''':
O programa solicita duas notas ao usuário e calcula a média final.
ele soma a nota 1 e a nota 2, e diz se foi aprovado ou nao, se for menor quê: 7 é reprovado
